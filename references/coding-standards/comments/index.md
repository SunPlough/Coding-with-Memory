# 注释规范

每次修改源码都加载本目录，并与对应语言规范一起使用。这里补充注释语义与中文写作规则，不替代 Google、语言工具或仓库专属的格式要求。

按需读取：

- [中文代码注释规范](chinese-comments.md)：注释语言选择、语义内容、AI 约束和审查方法。
- [各语言注释格式](language-formats.md)：文档注释语法和语言工具路由。
- [参考来源](sources.md)：更新提炼规则或审查来源时读取。

按以下顺序解决冲突：

```text
安全与合规
> 仓库注释政策
> 语言/框架文档格式
> 跨语言注释语义
> 用户沟通偏好
```

源码注释使用的语言属于仓库标准，不是用户 Memory 偏好。

## 执行边界

| 检查 | 首选执行方式 |
|---|---|
| 文档语法和必须的公共 API 文档 | 语言 Lint 或文档工具 |
| 注释掉的代码 | PMD/Lint/静态分析，再人工复核 |
| 裸露或格式错误的 TODO/FIXME/HACK | 仓库 Lint 或定向文本检查 |
| 注释中的秘密或个人数据 | Secret/Data Scanner |
| 重复、过时、臆测或低价值文本 | Agent diff 审查与人工审查 |
| 仓库注释语言一致性 | 按路径检查 diff，避免全局比例阈值 |

禁止使用注释率作为质量指标。注释密度不能证明质量，还会诱导 AI 生成噪声。
