# Google Style Guide 来源

以下是各语言文件使用的上游来源，最近核验日期为 2026-08-28。

Google Style Guide 仓库基线固定为 [`1809c769de31ba388c755ad15dd057a9ba8531fd`](https://github.com/google/styleguide/commit/1809c769de31ba388c755ad15dd057a9ba8531fd)，提交日期 2026-06-03。更新本地规则前，先将上游变化与该版本比较。

本地语言文件是面向 Agent 的可执行提炼，不是逐字镜像。提炼时保留规范等级、关键例外和验证工具；规则内容与上游冲突时以上游固定版本和项目覆盖为准。
